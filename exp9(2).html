Flash of Unstyled Content (FOUC) Prevention Explanation

When users set a preferred Dark Mode or custom layout, waiting for external JavaScript files to load causes a bright white flash on boot. To solve this, a lightweight synchronous inline script is placed in the HTML <head> that reads storage and applies attributes before DOM rendering begins. 

<!-- Placed in <head> before stylesheets render -->
<script>
  const prefs = JSON.parse(localStorage.getItem('user_app_preferences') || '{}');
  if (prefs.theme) document.documentElement.setAttribute('data-theme', prefs.theme);
</script>
